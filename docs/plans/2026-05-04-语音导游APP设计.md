# 游伴 - 智能语音导游APP

## 1. 项目概述

**APP名称**：游伴
**类型**：移动端语音讲解应用
**核心功能**：基于位置和图像的智能语音讲解，为自由行游客提供"走到哪讲到哪"的沉浸式游览体验
**目标用户**：自由行游客

## 2. 功能需求

### 2.1 核心功能

| 功能 | 描述 | 触发方式 |
|------|------|----------|
| 定位讲解 | GPS检测进入景点范围后自动讲解 | 室外/户外自动触发 |
| 拍照识别 | 摄像头对准景点进行图像识别讲解 | 室内/手动触发 |
| 语音问答 | 用户语音提问，智能回答并TTS播报 | 全程语音唤醒 |
| 游览路线 | 推荐最优参观路线，预估时间 | 手动查看 |

### 2.2 交互方式

- **全程语音控制**：语音输入 + 语音播报
- **真正解放双手**：无需手动操作，沉浸式体验

## 3. 技术架构

### 3.1 APP端技术

| 模块 | 技术选型 |
|------|----------|
| 框架 | Flutter / React Native |
| 定位服务 | 高德定位SDK |
| 图像识别 | 阿里云图像分析API |
| 语音输入 | 讯飞/百度语音识别SDK |
| 语音播放 | AudioPlayer |

### 3.2 云端服务

| 服务 | 用途 |
|------|------|
| Web服务 | 景点数据API、用户数据 |
| 图像识别API | 阿里云/腾讯云 |
| TTS服务 | 阿里云TTS（云端合成） |
| LLM服务 | 通义千问（语音问答） |

### 3.3 数据层

| 存储 | 用途 |
|------|------|
| 本地SQLite | 热门景点缓存、用户足迹 |
| 云端MySQL | 景点详情、用户数据 |
| CDN | 景点图片、音频资源 |

## 4. 数据来源

**混合方式**：
- 热门景点：本地数据库预置
- 其他景点：在线API获取

## 5. 页面结构

### 5.1 首页（自动讲解）
- 顶部：当前景点名称 + 距离
- 中间：景点实景图/AR视野
- 底部：播放控制条、音量、暂停
- 悬浮：语音按钮（随时唤醒）

### 5.2 拍照讲解页
- 全屏摄像头取景框
- 识别成功后：弹出景点卡片（图片+名称+简介）
- 点击卡片：展开完整讲解

### 5.3 问答页
- 对话气泡形式展示QA历史
- 语音输入指示器（说话中动画）
- TTS播报时显示讲话内容

### 5.4 我的足迹
- 游览过的景点列表
- 已播放/未播放标记
- 累计参观时长

## 6. 数据流程

### 6.1 定位讲解流程
```
GPS定位 → 检测景点范围 → 拉取讲解数据 → TTS合成 → 语音播放 → 推送通知
```

### 6.2 拍照讲解流程
```
摄像头 → 图像帧 → 上传云端识别 → 匹配景点ID → 拉取讲解数据 → TTS播放
```

### 6.3 语音问答流程
```
语音输入 → ASR转文字 → LLM理解意图 → 检索上下文 → 生成回答 → TTS播报
```

## 7. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 无GPS信号 | 提示"正在搜索定位"，切换拍照模式 |
| 识别失败 | "抱歉没能认出这个景点，您可以手动搜索" |
| 网络断开 | 启用本地缓存讲解，离线模式提示 |
| TTS失败 | 回退到文字显示 + 降级为系统TTS |
